# SketchPound

SketchPound is a high-performance, real-time data processing platform for large-scale digital asset rendering and management.

With SketchPound, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchPound.git`
2. `cd SketchPound`
3. Install in editable mode: `pip install -e .`

## Configuration

SketchPound is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
